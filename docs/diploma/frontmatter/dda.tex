\chapter{Designations and Abbreviations}
\begin{SingleSpace}

Following designations and abbreviations are used in this work:\par\bigskip

\begin{description}[style=multiline,leftmargin=3.2cm,labelwidth=3.2cm]

  \item[ADR]      Architecture Decision Record
  \item[ALB]      Application Load Balancer (AWS)
  \item[API]      Application Programming Interface
  \item[ACM]      AWS Certificate Manager
  \item[APN]      Apple Push Notification service
  \item[AWS]      Amazon Web Services
  \item[BibTeX]   bibliographic database format used by LaTeX
  \item[CI/CD]    Continuous Integration / Continuous Delivery
  \item[CP-SAT]   Constraint Programming with SAT-based search (OR-Tools)
  \item[CRUD]     Create, Read, Update, Delete
  \item[DRF]      Django REST Framework
  \item[DAU]      Daily Active Users
  \item[DLQ]      Dead-Letter Queue
  \item[DR]       Disaster Recovery
  \item[EAS]      Expo Application Services
  \item[ECR]      Elastic Container Registry (AWS)
  \item[ECS]      Elastic Container Service (AWS)
  \item[ETL]      Extract, Transform, Load
  \item[FCM]      Firebase Cloud Messaging
  \item[GDPR]     General Data Protection Regulation
  \item[HF]       Hugging Face (recipe dataset host)
  \item[IaC]      Infrastructure as Code
  \item[ILP]      Integer Linear Programming
  \item[JSON]     JavaScript Object Notation
  \item[JSONL]    JSON Lines
  \item[JWT]      JSON Web Token
  \item[KZT]      Kazakhstani Tenge (currency)
  \item[LightGBM] Gradient boosting framework used for the ranker
  \item[LLM]      Large Language Model
  \item[LSH]      Locality-Sensitive Hashing
  \item[ML]       Machine Learning
  \item[MVP]      Minimum Viable Product
  \item[NDCG]     Normalised Discounted Cumulative Gain
  \item[OIDC]     OpenID Connect
  \item[ORM]      Object-Relational Mapping
  \item[OTA]      Over-the-Air (update)
  \item[PITR]     Point-in-Time Recovery (RDS)
  \item[PR]       Pull Request
  \item[RDS]      Relational Database Service (AWS)
  \item[REST]     Representational State Transfer
  \item[RPO]      Recovery Point Objective
  \item[RTO]      Recovery Time Objective
  \item[SDK]      Software Development Kit
  \item[SE]       Software Engineering
  \item[SLA]      Service Level Agreement
  \item[SLO]      Service Level Objective
  \item[SNS]      Simple Notification Service (AWS)
  \item[SQS]      Simple Queue Service (AWS)
  \item[SQL]      Structured Query Language
  \item[SSM]      Systems Manager (AWS)
  \item[TLS]      Transport Layer Security
  \item[ToC]      Table of Contents
  \item[ToS]      Terms of Service
  \item[USDA]     United States Department of Agriculture
  \item[UUID]     Universally Unique Identifier
  \item[VPC]      Virtual Private Cloud (AWS)
  \item[WAF]      Web Application Firewall (AWS)

\end{description}
